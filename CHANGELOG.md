# Changelog

## 1.1.0 — 2026-10-15

### Changed
- Report (`docs/vlm_aerodynamics_report.pdf`) rewritten in LaTeX (`docs/report/`) as a revised edition, with figures generated by the package (`make report`).

### Fixed (report)
- XFLR5 comparison and stall optimization recomputed with the correct geometry (Λc/4 = 12°) and constant wing area.
- Leading-edge sweep formula (sum, not product).
- Statements corrected: XFLR5 does show the root dip; cost grows polynomially with the mesh, not exponentially; a constant C_M,ac alone does not prove longitudinal stability; XFLR5 is open-source.
- Rounded values in the sectional-lift and basic/additional tables, broken figure/table/equation numbering, and "Link." placeholders in the appendix.

## 1.0.0 — 2026-10-15

Refactor of the original Colab notebook into an installable, tested package.

### Added
- `vlmwing` package (`src/vlmwing/`): geometry, solver, validation, optimization and plotting modules with a single source of truth for the wing geometry.
- `vlmwing` command that reproduces every table and figure (`--json` writes the numbers).
- Test suite: report values, physics limits (thin-airfoil slope at high aspect ratio, Helmbold bound), linearity, symmetry, equivalence with the original element-by-element influence matrix.
- CI: ruff, pytest on Python 3.9–3.13, command-line reproduction and notebook execution.
- `pyproject.toml`, `CITATION.cff`, Makefile targets.

### Changed
- Influence matrix vectorized with NumPy: identical to the original to 1e-12, about 40× faster at 320 panels; the full design-space search takes seconds instead of minutes.
- Notebook rewritten as `notebooks/vlm_analysis.ipynb`, using the package, with no Google Drive or download dependency.
- Figures regenerated with descriptive names and a consistent style.
- The stall search holds the wing area constant and varies the quarter-chord sweep, so aspect ratio and sweep refer to the same definitions as the baseline.

### Fixed
- Validation, mesh-convergence and optimization sections used a 20° leading-edge sweep instead of the baseline 12° quarter-chord sweep.
- Optimization fixed the root chord while changing the span, so the area was not 1 m² and the reported aspect ratio was wrong.
- XFLR5 loader dropped the first data row (`skiprows=1` on a file without header).
- README claimed XFLR5 does not show the root dip; its data does.
